# Issues #436, #438, and #439 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve joined Spaces across provisional room-list observations, allow replies to captionless media, and rank Active sidebar entries by attention in one PR.

**Architecture:** Keep all three semantics Rust-owned. Provisional room-list actions merge at the state reducer, timeline replyability is projected through the existing message-action DTO, and Active ordering composes a private attention rank with the existing activity comparator. React consumes these projections without reconstructing Matrix semantics.

**Tech Stack:** Rust (`koushi-state`, `koushi-core`), React/TypeScript, Tauri DTO serialization, Cargo tests, Vitest.

## Global Constraints

- Base all work on `origin/main` in the existing `agent/issues-436-438-439` worktree.
- Use RED → GREEN for every behavior change and record the failing and passing commands.
- Add no retry scheduler, persisted diagnostic ring, classification state machine, fallback room-list service, or speculative diagnostics.
- Reuse existing reducer, action DTO, attention projection, and activity comparator boundaries.
- Do not alter the vendored Matrix SDK.
- Preserve privacy: no real identifiers, names, message content, or raw SDK errors in fixtures or diagnostics.
- Keep #439, #436, #438, and the AGENTS rule in separate implementation commits; publish one PR and merge it with a merge commit, not squash.
