# Issue #759 Phase B1 checkpoint — Core command admission

Status: implemented, locally verified and Fireworks `reviewer-flash` approved `CORRECT-TO-CONTINUE`.

## Scope

- Added an optional Core-owned admission oneshot to `CoreCommandEnvelope`.
- `command_with_admission` settles only after `AppActor` handles the command and
  publishes its synchronous state; every command coalesced into one inbox batch
  settles exactly once at the resulting published generation.
- Commands with no state delta settle at the unchanged current generation.
- Queue acceptance is not settlement. Runtime/channel closure returns the typed
  existing `CommandSubmitError::RuntimeClosed`.
- Ordinary command submission and composer-lease submission remain unchanged.
- Added adapter-only v1 camelCase admission/settlement DTOs. No handler or
  frontend command-return migration is claimed in B1.
