# Issue #759 Phase C — focused projection settlement

## Scope

Phase C replaces renderer-owned focused projection acknowledgement with a private Core actor-tree commit lane. `FocusedProjectionCommitted` is emitted under the active timeline actor-generation lease and carries the exact request, full key, actor/timeline generation, item count, and target-presence facts. AppActor generation-fences the signal, settles the pending focused navigation through the reducer, publishes the state delta, and only then emits the existing typed intent terminal.

The `AcknowledgeTimelineProjection` route was deleted from Core, Tauri, DesktopApi/client/browser fake, App/TimelineView, QA helpers, and tests. Gap-repair render acknowledgement remains for Phase D.
