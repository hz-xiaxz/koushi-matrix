## Recon

The public DTO families are mostly pure, but a direct move would copy three
boundary defects: four account requests carry `PathBuf`, two QA-only Account
variants carry Tokio oneshot senders, and Core mints the Tauri thumbnail scheme.
`SyncOnce` is separately test-gated and carries only `RequestId`.

The approved design therefore uses:

- a pure `koushi-protocol` DTO crate;
- one narrow request-correlated native-artifact port;
- private Core QA commands under `test-hooks`;
- opaque thumbnail refs resolved by the existing link/media adapter port;
- a non-default `koushi-qa` binary/orchestration package.

## Implementation discovery

The first command-extraction wasm check rejected the approved
`koushi-protocol -> koushi-key` edge because the full key crate transitively
compiled `rand/getrandom`. The implementation stopped before committing that
slice. The plan now moves only `SessionKeyId` into protocol, leaves credential
account-name derivation in a `koushi-key` extension trait, and inverts the edge
to `koushi-key -> koushi-protocol`. Fireworks reviewed the amendment and
returned `CORRECT-TO-IMPLEMENT` before extraction resumed.

## Integrated implementation

- `koushi-protocol` now owns commands, events, identities, failures, command
  admission, versioned snapshots and state deltas; Core retains policy,
  projection and runtime implementation.
- `SessionKeyId` moved to protocol with redacted `Debug`; credential account-name
  derivation remains in the `koushi-key::SessionKeyIdCredentialNames` trait with
  byte-compatible tests.
- Native artifact paths cross only the request-correlated Core port. Registration
  is one-shot, exact-kind, cancellation-safe and cleaned on rejection.
- Core projects opaque thumbnail refs; the Tauri link/media adapter mints the
  custom URI, while browser fixtures may supply explicit data/blob URLs.
- Both QA binaries and complete orchestration trees moved unchanged to the
  non-default `koushi-qa` package. Runners, CI, source guards and operational
  docs resolve the new package/path.
